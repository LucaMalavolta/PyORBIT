# Local correlated jitter


`local_correlated_jitter` makes the extra white-noise term of a reference
dataset a polynomial function of the measurements in a second, associated
dataset. The two time series are cross-matched by epoch.

For matched measurements with associated value $x$, the jitter is

```{math}
:label: local_correlated_jitter_equation

\sigma_\mathrm{jit}(x) = \sum_{k=1}^{n} c_k(x-x_0)^k .
```

The model returns zero for reference epochs without a match. Since jitter is
added in quadrature to the measurement uncertainty, the default coefficient
boundaries are non-negative.

## Model definition and requirements

- model name: `local_correlated_jitter`
- requires both the reference and associated datasets to be loaded with the same epoch convention.

## Model parameters

The parameters `x_zero` and `c1`, ..., `cN` are dataset-specific. If `x_zero`
is omitted, it is fixed to the minimum of the matched associated values.

The polynomial coefficients `c1`, ..., `cN` are dataset-specific and have non-negative default boundaries.

## Keywords

Model-wide keywords, with the default value in boldface where applicable.

**reference**
* accepted values: dataset name
* required; names the dataset receiving the jitter model.

**associated**
* accepted values: dataset name
* required; names the dataset supplying the correlated values.

**threshold**
* accepted values: number in days | **`0.001`**
* maximum absolute epoch difference accepted as a match.

**order**
* accepted values: integer | **`1`**
* polynomial order.

**x_zero**
* accepted values: number | **automatically selected**
* reference value for the associated measurement.

## Examples

The associated dataset must be loaded by PyORBIT even when it contributes no
deterministic model of its own. Attach the correlated-jitter model to the
reference dataset:

```yaml
inputs:
  RV_data:
    file: datasets/RV.dat
    kind: RV
    models:
      - radial_velocities
      - activity_dependent_jitter
  activity_index:
    file: datasets/activity_index.dat
    kind: Act
    models: []

models:
  radial_velocities:
    model: radial_velocities
    planets: [b]
  activity_dependent_jitter:
    model: local_correlated_jitter
    reference: RV_data
    associated: activity_index
    threshold: 0.001
    order: 2
```

The epoch convention and offset must be identical in both files. Inspect the
cross-match count printed during initialization: an unexpectedly low count
usually indicates inconsistent time standards or an overly small threshold.

No dedicated configuration for this model is currently present in the
[PyORBIT examples repository](https://github.com/LucaMalavolta/PyORBIT_examples);
the excerpt is a minimal configuration sketch.
