# Polynomially modulated sinusoid


`sinusoid_polynomial_modulation` multiplies a sinusoid by a polynomial
envelope,

```{math}
:label: sinusoid_polynomial_modulation_equation

f(t) = A\,\sin\!\left(\frac{t-T_\mathrm{ref}}{P}-\phi\right)
\sum_{k=s}^{n} c_k
\left(\frac{t-x_0-x_\mathrm{offset}}{\Delta t}\right)^k .
```

The implementation uses `sine_period` directly in the sine argument. The
polynomial coefficients `poly_cN`, `sine_period`, `sine_phase` and `x_zero`
are common; `sine_amp` and the optional `x_offset` are dataset-specific.

## Keywords

| Keyword | Default | Meaning |
| --- | --- | --- |
| `order` | `1` | highest polynomial order |
| `time_interval` | `1.0` | scale $\Delta t$ applied to the polynomial coordinate |
| `time_offset` | `False` | enable the local `x_offset` parameter |
| `reference_dataset` | none | dataset whose `x_offset` is fixed to zero |
| `x_zero` | automatic | polynomial reference epoch |

The constant coefficient `poly_c0` is fixed to one. If `x_zero` is omitted,
PyORBIT selects `Tref` when it lies inside a dataset and otherwise uses an
average epoch.

## Example

```yaml
models:
  evolving_sine:
    model: sinusoid_polynomial_modulation
    order: 2
    time_interval: 365.25
    time_offset: True
    reference_dataset: RV_HARPS
    boundaries:
      sine_period: [5.0, 100.0]
      sine_amp: [-20.0, 20.0]
      sine_phase: [0.0, 360.0]
      poly_c1: [-2.0, 2.0]
      poly_c2: [-2.0, 2.0]
```

No dedicated polynomially modulated sinusoid configuration is currently
present in the
[PyORBIT examples repository](https://github.com/LucaMalavolta/PyORBIT_examples);
the snippet is a minimal configuration sketch.
