# Detrending models

These models describe correlations between the measured quantity and ancillary
variables such as detector position, background, airmass or image quality.
Ancillary columns must have a header and the same number and ordering of rows
as the main dataset.

The deterministic models can use local coefficients, which is the default, or
share their coefficients among datasets. The Matérn-3/2 model instead treats
the ancillary variables as the coordinates of a Gaussian process.
