# Exponential detrending

```{warning}
 This page is a stub generated by Codex. The content has **not** been verified yet; important information (references, links to external packages) may be missing, and mistakes may be present
```

`exponential_detrending` uses the same ancillary-variable interface and
coefficient names as `polynomial_detrending`, but exponentiates the combined
polynomial trend. With the default base it returns

```{math}
:label: exponential_detrending_equation

f(\boldsymbol{x}) = 10^{b + \sum_j\sum_{k=s}^{n_j}
c_{j,k}(x_j-x_{0,j})^k}.
```

Set `natural_base: True` to use the natural exponential instead. This form is
useful for positive multiplicative systematics or for trends that are close to
linear in logarithmic flux.

## Configuration

```yaml
inputs:
  LC_ground:
    file: datasets/lightcurve.dat
    ancillary: datasets/lightcurve_ancillary.dat
    kind: Phot
    models:
      - transit_model
      - extinction_detrending

models:
  extinction_detrending:
    model: exponential_detrending
    natural_base: True
    detrending_variables:
      airmass: 1
      background: 2
```

The required `detrending_variables` mapping and the keywords `order`,
`local_model`, `use_common_parameters`, `use_median_xzero`, `x_zero`,
`starting_order`, `include_zero_point` and `baseline_value` behave as described
for [polynomial detrending](polynomial_detrending.md).

The generated parameters are `det_<variable>_cN` and
`x_zero_<variable>`. Parameters are local by default; common-parameter aliases
can be used when several datasets share the same ancillary relation.

No dedicated exponential-detrending configuration is currently present in
the [PyORBIT examples repository](https://github.com/LucaMalavolta/PyORBIT_examples);
the excerpt is a minimal configuration sketch.
