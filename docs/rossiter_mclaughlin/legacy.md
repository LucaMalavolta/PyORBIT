# Legacy CCF Rossiter–McLaughlin model

`rossitermclaughlin_legacy` numerically integrates the occulted stellar disk,
constructs a CCF on a velocity grid and measures its displacement with a
Gaussian fit. It predicts a classical radial-velocity anomaly for one planet.

The implementation requires `lmfit`; `numba` is used when available. It also
requires a `spectrograph` common object defining the CCF grid and broadening
parameters.

## Model options

| Keyword | Default | Meaning |
| --- | --- | --- |
| `star_ngrid` | `101` | number of grid points along each stellar-disk axis |
| `time_step` | `149` | integration step in seconds for finite exposures |
| `limb_darkening` | `limb_darkening` | selected limb-darkening common object |
| `spectrograph` | `spectrograph` | selected spectrograph common object |

The input dataset needs an `exptime` ancillary column in seconds. Stellar-line
mode uses the common `natural_contrast` and `natural_broadening`; an
instrument-specific line instead uses `line_contrast` and `line_broadening`.
The spectrograph also sets `rv_min`, `rv_max` and `rv_step` in km/s.

```yaml
common:
  spectrograph:
    model: spectrograph
    rv_min: -20.0
    rv_max: 20.0
    rv_step: 0.25
    fixed:
      instrumental_broadening: 1.1

models:
  rm_legacy:
    model: rossitermclaughlin_legacy
    planets: [b]
    limb_darkening: limb_darkening_RV
    spectrograph: spectrograph
    star_ngrid: 151
    time_step: 120
```

The planet, `star_parameters`, limb-darkening object and input dataset follow
the same layout as the [PyARoME example](pyarome.md). Increasing `star_ngrid`
improves spatial resolution at a substantial computational cost.

The `RM_revolutions_example` repository contains historical classical-RM
configurations, but their `rossitermclaughlin_precise` name is not one of the
current registry names. The excerpt above therefore documents the current
`rossitermclaughlin_legacy` entry directly.
