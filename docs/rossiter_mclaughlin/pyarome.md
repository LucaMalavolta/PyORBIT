`rossitermclaughlin_pyarome` evaluates the analytical ARoME prescription
through the external `pyarome` package. `rossitermclaughlin_arome` is an alias
for the same implementation.

The model predicts the classical radial-velocity anomaly and assumes
quadratic limb darkening.

## Model definition and requirements

- model names: `rossitermclaughlin_pyarome` and alias `rossitermclaughlin_arome`
- requires the external `pyarome` package, quadratic limb darkening, and planet and spectrograph common objects.

## Model parameters

In addition to the orbital and transit geometry it
uses `lambda`, `R_Rs`, `v_sini`, `macroturbulence`,
`instrumental_broadening` and `measured_ccf_width`.

## Keywords

Model-wide keywords, with the default value in boldface.

**measurement_technique**
* accepted values: **`ccf`** | `iodine`
* selects the CCF or iodine-cell expression, respectively.

**limb_darkening**
* accepted values: quadratic limb-darkening common-object name | **`limb_darkening`**
* selects the quadratic limb-darkening common object.

**spectrograph**
* accepted values: spectrograph common-object name | **`spectrograph`**
* selects the instrumental-parameter common object.

## Examples

```yaml
inputs:
  RV_transit:
    file: datasets/RV_transit.dat
    kind: RV
    models:
      - radial_velocities
      - rm_pyarome

common:
  planets:
    b:
      orbit: circular
      parametrization: Eastman2013_Tcent
      boundaries:
        P: [2.0, 3.0]
        Tc: [59000.0, 59001.0]
        R_Rs: [0.05, 0.2]
        lambda: [-180.0, 180.0]
  star:
    star_parameters:
      boundaries:
        v_sini: [0.0, 20.0]
    limb_darkening_RV:
      type: ld_quadratic
      parametrization: Kipping
  spectrograph:
    model: spectrograph
    fixed:
      instrumental_broadening: 1.1
      measured_ccf_width: 5.0

models:
  radial_velocities:
    planets: [b]
  rm_pyarome:
    model: rossitermclaughlin_pyarome
    planets: [b]
    limb_darkening: limb_darkening_RV
    spectrograph: spectrograph
    measurement_technique: ccf
```

No configuration using the current registry name is present in the
[PyORBIT examples repository](https://github.com/LucaMalavolta/PyORBIT_examples);
the snippet is a minimal integration example.
